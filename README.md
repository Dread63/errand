# browser-control

A Chrome extension that provides an interactive side-panel browsing agent (live cursor, highlights, approvals) powered by OpenAI-compatible models — local models via MTPLX over Tailscale, or hosted models via OpenCode Go.

Status: design phase. See [`docs/superpowers/specs/2026-10-04-browser-agent-extension-design.md`](docs/superpowers/specs/2026-10-04-browser-agent-extension-design.md).
